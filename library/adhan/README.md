# SAKINA adhan library (hostable)

Upload this whole folder to any static host (CDN bucket, GitHub Pages, …) and set
`extra.adhanLibraryUrl` in app.json to its base URL. The app then fetches `catalogue.json` (validated, SHA-256 pinned per file)
and can offer every voice for download without an app update.

2 voices · 2.4 MB.
Each file is a modification of a Creative Commons recording; see the `credit` block of each voice in `catalogue.json` for author, licence and changes — attribution must stay visible in the app.
